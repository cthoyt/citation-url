##############
 Installation
##############

The most recent release can be installed from `PyPI
<https://pypi.org/project/citation-url>`_ with uv:

.. code-block:: console

    $ uv pip install citation-url

or with pip:

.. code-block:: console

    $ python3 -m pip install citation-url

*********************
 Installing from git
*********************

The most recent code and data can be installed directly from GitHub with uv:

.. code-block:: console

    $ uv pip install git+https://github.com/cthoyt/citation-url.git

or with pip:

.. code-block:: console

    $ python3 -m pip install git+https://github.com/cthoyt/citation-url.git

****************************
 Installing for development
****************************

To install in development mode with uv:

.. code-block:: console

    $ git clone git+https://github.com/cthoyt/citation-url.git
    $ cd citation-url
    $ uv pip install -e .

or with pip:

.. code-block:: console

    $ python3 -m pip install -e .
